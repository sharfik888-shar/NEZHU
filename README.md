# NEZHU

Мессенджер в стиле Telegram.  
Стек: Next.js + Supabase + TypeScript + Tailwind CSS

## Функции (план)

- [ ] Регистрация и вход
- [ ] Профиль пользователя
- [ ] Личные чаты
- [ ] Групповые чаты
- [ ] Каналы
- [ ] Настройки
- [ ] Realtime сообщения
